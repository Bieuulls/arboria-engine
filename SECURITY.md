# Security Policy

## Supported Versions

Only the latest release on the primary development branch is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security and integrity of our users and systems seriously. If you believe you have discovered a security vulnerability in ARBORIA ENGINE (such as unsafe native memory handling, arbitrary code execution during mesh parsing/baking, buffer overflow in GPU buffers or shader compilation):

1. **Do not disclose the issue publicly** in an open issue, pull request, or public forum.
2. Please report security issues privately using [GitHub Security Advisories](https://github.com/Bieuulls/arboria-engine/security/advisories/new) or by reaching out privately to the repository maintainer.
3. Include:
   - Description of the vulnerability.
   - Steps to reproduce or proof-of-concept (POC) asset/script.
   - Potential impact and affected versions/platforms.

We will acknowledge receipt within 48 hours and work with you on a timeline for verification, patching, and coordinated disclosure.
